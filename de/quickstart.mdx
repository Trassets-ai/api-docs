Diese Anleitung bringt dich in wenigen Minuten von null zum erfolgreichen API-Call. Du brauchst eine Unix-ähnliche Shell mit installiertem curl.

<Steps>
  <Step title="API-Key erstellen">
    Besuche [portal.api.trassets.ai](https://portal.api.trassets.ai) und erstelle einen Account. Erzeuge einen API-Key und speichere ihn sicher. Der Klartext-Key wird nur einmal angezeigt.
  </Step>
  <Step title="Deinen ersten Request stellen">
    Setze deinen Key als Umgebungsvariable und rufe den Property-Endpunkt mit einer kleinen Seitengröße ab.

    ```bash
    export TRASSETS_API_KEY="sk_live_…"
    curl "https://api.trassets.ai/property/properties?limit=1" \
      -H "X-API-Key: $TRASSETS_API_KEY"
    ```

    Die API liefert ein JSON-Array von Objekten zurück. Eine typische Antwort sieht so aus:

    ```json
    [
      {
        "property_id": 42,
        "obj_name": "Musterstrasse 12",
        "entrance_1": "Musterstrasse 12",
        "postcode": "10115",
        "city": "Berlin"
      }
    ]
    ```

    <Note>
      Der genaue Umfang der Felder hängt von deinem Kunden-Schema ab — Spalten werden
      dynamisch aus deiner Datenbank gelesen. Siehe das [Feldglossar](/de/data-model/field-glossary)
      für Felder, die über mehrere Endpunkte hinweg vorkommen.
    </Note>

    Geschafft! Du hast dich authentifiziert und deine erste Zeile Immobiliendaten abgerufen.
  </Step>
  <Step title="Nächste Schritte">
    - Lies [Authentifizierung](/de/authentication) für Key-Management und Zugriffsstufen.
    - Lies [Endpunkt-Typen](/de/concepts/endpoint-types) dazu, wann Category- und wann Raw-Endpunkte sinnvoll sind.
    - Durchsuche die [API-Referenz-Übersicht](/de/api-reference/introduction) für die vollständige Endpunktliste.
  </Step>
</Steps>
