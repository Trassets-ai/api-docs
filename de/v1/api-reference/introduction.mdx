Die `/v1/`-Endpunkte sind die versionierte Schnittstelle auf dieselben Immobiliendaten. Basis-URL: `https://api.trassets.ai`. Sende deinen API-Key im `X-API-Key`-Header bei jedem Request. Alle Antworten sind JSON.

Jede `/v1/{category}/{api_table}`-Response ist ein JSON-Objekt: die Zeilen stehen in `data`, daneben die Pagination-Felder. Siehe [Response-Struktur](/de/v1/response-shape-conventions) für die Objekt-, Array- und Code/Label-Muster, denen die Zeilen folgen.

## Endpunkt-Typen

| Typ | Pfad-Muster | Pagination | Anwendungsfall |
| --- | --- | --- | --- |
| Category-Endpunkte | `/v1/{category}/{api_table}` | Cursor-basiert (`limit` / `cursor`, `next_cursor` im Body) | Business-Abfragen, Dashboards, inkrementelle Abrufe |
| Raw-Endpunkte | `/v1/raw/{table_name}` | Cursor-basiert (`cursor` aus `next_cursor` im Body) | Bulk-Sync, vollständige Exporte, Data Warehousing |

Raw-Endpunkte sind generisch pro Kunde (keine tabellenweise Inhaltsprüfung). Sie nutzen dieselben Response-Schlüssel wie die Category-Endpunkte (`total`).

### Pagination

Nur Cursor, die Pagination-Felder stehen im Body: `total` und `next_cursor` (`null` = keine weitere Seite). Ein `offset` gibt es nicht; ein Request mit `offset` liefert `400 Bad Request`. Details: [Pagination](/de/v1/concepts/pagination).

## Fehlerformat

Fehler folgen [RFC 7807](https://datatracker.ietf.org/doc/html/rfc7807) (`application/problem+json`). Jedes Fehlerobjekt enthält `type`, `title`, `status`, `detail` und `instance`. Siehe [Fehler](/de/concepts/errors) für eine vollständige Liste der Status-Codes und Hinweise zu Wiederholungsversuchen.

## Versionierung

Alle Tabellen-Endpunkte liegen unter `/v1/`; die früheren Pfade ohne Versionspräfix liefern `404`. Siehe [Versionierung](/de/concepts/versioning).

## Endpunkt-Gruppen ohne Versions-Präfix

Zwei Endpunkt-Gruppen existieren einmal für die gesamte API und tragen kein `/v1/`-Präfix. Catalog und Delta Sync stehen in der Seitenleiste unterhalb der Kategorien.

| Gruppe | Endpunkt | Was unter `/v1/` zu erwarten ist |
| --- | --- | --- |
| Catalog | `GET /catalog` | Listet alle Kategorien und Tabellen, die die API bereitstellt. Für das `/v1/`-Inventar die [Datenmodell-Übersicht](/de/v1/data-model/overview) nutzen. |
| Delta Sync | `GET /changes` | Liefert Sync-Zeitstempel pro Tabelle. Benötigt den Parameter `since` (ISO-8601 UTC). |
