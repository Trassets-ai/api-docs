Die Trassets Data API ist eine Read-only-REST-Schnittstelle über Immobiliendaten — Objekte, Verträge, Buchhaltung und mehr — gebaut für Softwarepartner und Integratoren, die an Trassets-verwaltete Portfolios andocken. Jede Anfrage wird per `X-API-Key`-Header authentifiziert, jede Antwort ist JSON.

Dieser Bereich behandelt `/v1/`, die versionierte Pfad-Familie der API (`/v1/{category}/{api_table}`), mit einer Response-Struktur, die pro Endpunkt stabil bleibt, sobald sie veröffentlicht ist.

## Für wen ist die API gedacht?

- **Softwarepartner & Integratoren**, die Tools auf Basis von Trassets-verwalteten Portfolios bauen.
- **IT-Teams der Immobilienverwalter selbst**, die interne Systeme oder Reporting an Live-Portfoliodaten anbinden.
- **Data- & BI-Teams**, die Data Warehouses, Dashboards oder Analyse-Pipelines speisen.
