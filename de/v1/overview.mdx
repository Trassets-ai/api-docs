<Warning>
  `/v1/` ist live, aber noch nicht vollständig: Endpunkte werden nach und nach freigeschaltet, sobald die jeweilige Tabelle das Review durchlaufen hat. Der aktuelle Stand steht im Tab **API-Referenz** (generiert aus der Live-`openapi-v1.json`) — nicht davon ausgehen, dass eine in der unversionierten API gelistete Tabelle automatisch auch unter `/v1/` erreichbar ist.
</Warning>

`/v1/` spiegelt die Pfade der unversionierten API unter einem `/v1/{category}/{api_table}`-Präfix. Eine Tabelle erscheint erst, wenn sie gegen die [Konventionen für die Response-Struktur](/de/v1/response-shape-conventions) reviewt wurde — bis dahin weiterhin den unversionierten Pfad für diese Tabelle nutzen.
