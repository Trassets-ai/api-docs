---
title: "Erste Schritte mit der Data API v1"
description: "In drei Schritten zum API-Key und zum ersten Call an v1 der Data API."
sidebarTitle: "Quickstart"
---

Diese Anleitung bringt dich in wenigen Minuten von null zum erfolgreichen `/v1/`-API-Call. Du brauchst eine Unix-ähnliche Shell mit installiertem curl.

<Steps>
  <Step title="API-Key erstellen">
    Trassets richtet den Portal-Zugang für deine Organisation ein (keine öffentliche Registrierung). Melde dich unter [portal.api.trassets.ai](https://portal.api.trassets.ai) an, erzeuge selbst einen API-Key und speichere ihn sicher. Der Klartext-Key wird nur einmal angezeigt.
  </Step>
  <Step title="Deinen ersten Request stellen">
    Setze deinen Key als Umgebungsvariable und rufe `technical_objects` ab — eine Tabelle aus der Kategorie Property.

    ```bash
    export TRASSETS_API_KEY="sk_live_…"
    curl "https://api.trassets.ai/v1/property/technical_objects?limit=1" \
      -H "X-API-Key: $TRASSETS_API_KEY"
    ```

    Die API liefert ein JSON-Objekt zurück: die Zeilen stehen in `data`, dazu `count`, `next_cursor` (`null` auf der letzten Seite) und `total`. Eine typische Antwort sieht so aus:

    ```json
    {
      "data": [
        {
          "technical_object_id": 5231,
          "property_id": 1622,
          "floor_area_id": null,
          "name": "Aufzug Hof",
          "type": "Aufzug",
          "built_date": "1998-06-01",
          "is_meter": false
        }
      ],
      "count": 1,
      "next_cursor": "eyJjb2wiOiAi…",
      "total": 214
    }
    ```

    <Note>
      Wie `technical_objects` mit dem Rest von `/v1/` verknüpft ist, steht in der
      [v1 Datenmodell-Übersicht](/de/v1/data-model/overview).
    </Note>

    Geschafft! Du hast dich authentifiziert und deine erste Zeile Daten über einen
    `/v1/`-Endpunkt abgerufen.
  </Step>
  <Step title="Nächste Schritte">
    - Lies [Authentifizierung](/de/v1/authentication) für Key-Management und Zugriffsstufen.
    - Prüfe die [v1 Übersicht](/)für einen Überblick über die `/v1/`-Tabellen.
    - Lies die [Response-Struktur](/de/v1/response-shape-conventions) für die Strukturregeln, denen jede `/v1/`-Response folgt.
    - Durchsuche die [v1 Datenmodell](/de/v1/data-model/overview)-Seiten für die Feldreferenz jeder Tabelle.
  </Step>
</Steps>
