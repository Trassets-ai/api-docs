Die Data API liefert Fehler im RFC-7807-Format (`application/problem+json`). Jede Fehlerantwort enthält einen konsistenten Satz von Feldern, sodass du das Problem programmatisch erkennen, die Details protokollieren und entscheiden kannst, wie du den Request wiederholst oder korrigierst.

## Problem-JSON-Format

Jeder Fehlerantwort-Body enthält diese Felder:

| Feld | Typ | Beschreibung |
| --- | --- | --- |
| `type` | string | Eine URI, die den Fehlertyp identifiziert, eine pro Statuscode (siehe [Statuscodes](#statuscodes)). Zwei Export-Limits für Raw-Tabellen nutzen eigene Typen, siehe [Too Many Requests](#too-many-requests). |
| `title` | string | Eine kurze, menschenlesbare Zusammenfassung des Fehlertyps. |
| `status` | integer | Der HTTP-Statuscode. |
| `detail` | string | Eine detaillierte, menschenlesbare Erklärung dieses konkreten Vorfalls. |
| `instance` | string | Der Request-Pfad, der den Fehler ausgelöst hat. |

Beispiel-Fehlerantwort für einen ungültigen API-Key:

```json
{
  "type": "https://docs.trassets.ai/concepts/errors#forbidden",
  "title": "Forbidden",
  "status": 403,
  "detail": "Invalid API key",
  "instance": "/v1/property/properties"
}
```

## Statuscodes

Jeder Statuscode hat eine feste `type`-URI, die auf seinen Abschnitt auf dieser Seite zeigt. Verzweige im Code über `status` oder `type`, `detail` ist für Logs und Meldungen gedacht. Die Überschriften bleiben englisch, damit die Anker zur URI passen.

### Bad Request

**400** · `type`: `https://docs.trassets.ai/concepts/errors#bad-request`

Ein erforderlicher Filter fehlt oder ein Parameterwert ist ungültig. Prüfe die Endpunkt-Dokumentation auf erforderliche Query-Parameter und lies das Feld `detail`. Ein `cursor`, der verändert wurde, nicht von der API stammt oder zu einem anderen Endpunkt gehört, liefert `Invalid cursor`: Gib `next_cursor` unverändert an den Endpunkt weiter, von dem er stammt.

### Unauthorized

**401** · `type`: `https://docs.trassets.ai/concepts/errors#unauthorized`

Der API-Key fehlt oder ist abgelaufen. Sende den `X-API-Key`-Header bei jedem Request. Steht in `detail` `API key expired`, nimm einen noch gültigen Key.

### Forbidden

**403** · `type`: `https://docs.trassets.ai/concepts/errors#forbidden`

Der Key wird abgelehnt oder die Zugriffsstufe fehlt. Der Key ist unbekannt oder deaktiviert, oder er wurde für den MCP-Server erstellt (`API key not enabled for this channel`, siehe [Kanal](/de/v1/authentication#kanal)), oder er hat keine Berechtigung für diesen Endpunkt oder diese Tabelle, oder er ist auf Properties eingeschränkt und die Tabelle hat keine `property_id`-Spalte. Prüfe das Feld `detail`. Kontaktiere den Trassets-Support, um deine Zugriffsstufe zu ändern.

### Not Found

**404** · `type`: `https://docs.trassets.ai/concepts/errors#not-found`

Unbekannter Endpunkt. Überprüfe den URL-Pfad sowie den Category- oder Tabellennamen.

### Conflict

**409** · `type`: `https://docs.trassets.ai/concepts/errors#conflict`

Der Snapshot hat sich geändert: Die Tabelle wurde während deiner Pagination neu synchronisiert. Starte neu ab der ersten Seite ohne `cursor`. Siehe [Pagination](/de/v1/concepts/pagination).

### Unprocessable Entity

**422** · `type`: `https://docs.trassets.ai/concepts/errors#unprocessable-entity`

Ein Query-Parameter hat die Validierung nicht bestanden. Prüfe das `detail`-Feld für den genauen Parameter und die Einschränkung.

### Too Many Requests

**429** · `type`: `https://docs.trassets.ai/concepts/errors#too-many-requests`

Du hast das Limit von 2.500 Requests pro Stunde deines API-Keys überschritten. Warte die Sekunden aus dem `Retry-After`-Header ab und versuche es dann erneut, siehe [Rate-Limits](/de/concepts/rate-limits).

Exporte von Raw-Tabellen haben zwei zusätzliche Limits mit eigenem `type`: `too_many_parallel_exports`, wenn zu viele Export-Requests deines Accounts gleichzeitig laufen, und `export_rate_limited`, wenn ein für deinen Account oder die Tabelle eingestelltes Stundenlimit für Exporte aufgebraucht ist.

### Internal Server Error

**500** · `type`: `https://docs.trassets.ai/concepts/errors#internal-server-error`

Ein serverseitiger Fehler ist aufgetreten. Wiederhole den Request nach einer kurzen Verzögerung und [kontaktiere den Support](#support-kontaktieren), falls das Problem weiterhin besteht.

### Service Unavailable

**503** · `type`: `https://docs.trassets.ai/concepts/errors#service-unavailable`

Die API ist gerade überlastet oder konnte den Request im Moment nicht prüfen. Warte die Sekunden aus dem `Retry-After`-Header ab und versuche es dann erneut.

<Warning>
  Ein **401** bedeutet, dass der `X-API-Key`-Header fehlt oder der Key abgelaufen ist. Ein unbekannter oder deaktivierter Key liefert **403**, ebenso ein für den MCP-Server erstellter Key oder ein gültiger Key ohne die erforderliche Zugriffsstufe. Das Feld `detail` zeigt, welcher Fall vorliegt.
</Warning>

## Support kontaktieren

Jede Antwort der API trägt den Header `X-Request-ID` mit einer UUID, auch jede Fehlerantwort. Antworten, die der Load Balancer selbst schickt, haben keine ID, etwa die Weiterleitung von `http://` oder ein `502`, solange die API nicht erreichbar ist. Der Header ist per CORS freigegeben, Browser-Clients können ihn also ebenfalls lesen. Wenn du dich wegen eines Requests an den Trassets-Support wendest, schick seine `X-Request-ID` mit. Damit finden wir genau diesen Request in unseren Logs, die wir 30 Tage aufbewahren.

```bash
curl -i "https://api.trassets.ai/v1/catalog" \
  -H "X-API-Key: $TRASSETS_API_KEY"
# x-request-id: 0b6c1f3e-5a2d-4c8e-9f71-2d4e6a8b0c13
```

Die ID erzeugt immer der Server. Einen `X-Request-ID`-Header im Request ignoriert die API.
