Die Trassets Data API wird derzeit über den Basis-Pfad ohne Versionspräfix bereitgestellt. URL-Versionierung unter `/v1/` ist für ein kommendes Release geplant; ab diesem Zeitpunkt werden Breaking Changes nur noch unter einem neuen Versionspfad eingeführt. Bis die Versionierung vollständig durchgesetzt ist, kann die API Breaking Changes ohne separaten Versionspfad erhalten.

## Aktueller Stand

Heute sind alle Endpunkte direkt unter der Basis-URL verfügbar:

```text
https://api.trassets.ai/accounting/accounts
https://api.trassets.ai/raw/ixhaus_contracts
https://api.trassets.ai/changes
```

Die OpenAPI-Spezifikation referenziert in einigen Beispielen bereits `/v1/`, aber das versionierte Präfix wird auf Gateway-Ebene noch nicht erzwungen.

## Kommende Versionierung

Sobald die URL-Versionierung live ist, wird der Standardpfad zu:

```text
https://api.trassets.ai/v1/accounting/accounts
```

Die aktuellen unversionierten Pfade funktionieren nach dem Start von `/v1/` noch für ein Deprecation-Fenster weiter und werden danach abgeschaltet {/* TODO: Sunset-Datum, sobald API-Team Rollout bestätigt */}. Breaking Changes (wie umbenannte Felder, entfernte Query-Parameter oder veränderte Response-Formate) werden danach ausschließlich unter einem neuen Präfix wie `/v2/` eingeführt, nie auf einer bereits veröffentlichten Version.

<Warning>
  Bis `/v1/` erzwungen wird, können Breaking Changes auf den aktuellen Basis-Pfaden auftreten. Beobachte die Release Notes und teste deine Integrationen nach jedem angekündigten Update. Sobald `/v1/` live ist: Migriere vor dem Sunset-Datum — unversionierte Pfade werden dann abgeschaltet, nicht weitergeleitet. Kontaktiere den Trassets-Support, falls du Migrationshilfe benötigst.
</Warning>

Um vorbereitet zu bleiben, abonniere die Trassets Release Notes und halte deinen Integrationscode flexibel genug, um sich an neue Felder oder Parameteränderungen anzupassen.
