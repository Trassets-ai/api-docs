---
title: "Error Format"
description: "RFC 7807 problem+json"
---

Errors follow [RFC 7807](https://datatracker.ietf.org/doc/html/rfc7807) (`application/problem+json`):
`type`, `title`, `status`, `detail`, `instance`.

| Status | Meaning |
|--------|---------|
| 400 | Missing required filter |
| 401 | Invalid API key |
| 403 | Missing access tier |
| 404 | Unknown endpoint |
| 429 | Rate limit (500 req/h) |
| 500 | Internal error |
