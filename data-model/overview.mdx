The Trassets Data API organises real-estate data into five domains. Each domain contains normalised tables you can query through category endpoints, or you can access the underlying raw tables directly. The domains share common identifiers so you can join data across categories to build a complete view of your portfolio.

## Join keys

`property_id` is the primary join key across all domains. Use it to link real-estate objects with contract debits, accounting bookings, and meter readings that belong to the same property.

`floor_area_id` references the property structure table and connects units and floor areas to other records such as contract debits and booking headers. This lets you aggregate financial or consumption data at the level of an individual unit or floor area.
