All table endpoints of the Data API live under `/v1/`, e.g.:

```text
https://api.trassets.ai/v1/accounting/budgets
https://api.trassets.ai/v1/raw/sollart
```

Every `/v1/` route follows the [response structure](/v1/response-shape-conventions) rules. For the current list of available tables, check the **API Reference** tab.

<Warning>
  `/v1/` is still a **preview**: until it is declared stable, breaking changes can land on a published `/v1/` path (for example, `/v1/operations/projects` changed to one row per project). Check the field reference after each release.
</Warning>

## Endpoints without a version prefix

`GET /catalog` and `GET /changes` exist once for the whole API and carry no prefix. The `endpoint_url` that `/changes` returns always starts with `/v1/` — for raw tables, too (`/v1/raw/...`).

## Unversioned paths are switched off

The former category and raw paths without a version prefix (e.g. `/accounting/accounts` or `/raw/sollart`) are switched off and return `404` — there is no redirect. Use the `/v1/` path instead.
