<p><mark>Category endpoints are available only under `/v1/{category}/{api_table}`. The unversioned category paths, e.g. `/accounting/accounts`, return `404 Not Found`.</mark></p>

## Current State

Tables are available under `/v1/`, e.g.:

```text
https://api.trassets.ai/v1/accounting/budgets
https://api.trassets.ai/v1/raw/sollart
```

Every `/v1/` route follows the [response structure](/v1/response-shape-conventions) rules. <mark>For the current list of available tables, check the **API Reference** tab.</mark>

<p><mark>Raw tables are also served under the base path `/raw/{table_name}` with the same data; there the response key is `total_rows` instead of `total`. Use `/v1/raw/{table_name}`.</mark></p>

`GET /catalog` and `GET /changes` have no version prefix.

<Warning>
  Once a table has a `/v1/` route, breaking changes land under a new prefix such as `/v2/`, not on the published path. <mark>The unversioned raw paths carry no such guarantee.</mark>
</Warning>

## Tables without a /v1/ route

<p><mark>`operations/offers` and `operations/orders` are currently not available. They will follow under `/v1/` in a later release.</mark></p>
