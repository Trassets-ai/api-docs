The Data API returns errors in the RFC 7807 format (`application/problem+json`). Every error response includes a consistent set of fields so you can programmatically detect the problem, log the details, and decide how to retry or correct the request.

## Problem JSON Format

Every error response body contains these fields:

| Field | Type | Description |
| --- | --- | --- |
| `type` | string | A URI that identifies the error type, one per status code (see [Status Codes](#status-codes)). Two export limits on raw tables use their own types, see [Too Many Requests](#too-many-requests). |
| `title` | string | A short, human-readable summary of the error type. |
| `status` | integer | The HTTP status code. |
| `detail` | string | A detailed, human-readable explanation of this specific occurrence. |
| `instance` | string | The request path that produced the error. |

Example error response for an invalid API key:

```json
{
  "type": "https://docs.trassets.ai/concepts/errors#forbidden",
  "title": "Forbidden",
  "status": 403,
  "detail": "Invalid API key",
  "instance": "/v1/property/properties"
}
```

## Status Codes

Every status code has a fixed `type` URI that points to its section on this page. Use `status` or `type` to branch in your code, and `detail` for logs and messages.

### Bad Request

**400** · `type`: `https://docs.trassets.ai/concepts/errors#bad-request`

A required filter is missing or a parameter value is invalid. Check the endpoint documentation for required query parameters and read the `detail` field. A `cursor` that was modified, not issued by the API, or issued for another endpoint returns `Invalid cursor`: pass `next_cursor` unchanged to the endpoint it came from.

### Unauthorized

**401** · `type`: `https://docs.trassets.ai/concepts/errors#unauthorized`

The API key is missing or expired. Send the `X-API-Key` header with every request. If `detail` says `API key expired`, use a key that is still valid.

### Forbidden

**403** · `type`: `https://docs.trassets.ai/concepts/errors#forbidden`

The key is rejected or the access tier is missing. The key is unknown or disabled, or it was created for the MCP server (`API key not enabled for this channel`, see [Channel](/v1/authentication#channel)), or it has no permission for this endpoint or table, or it is restricted to properties and the table has no `property_id` column. Check the `detail` field. Contact Trassets support to change your access tier.

### Not Found

**404** · `type`: `https://docs.trassets.ai/concepts/errors#not-found`

Unknown endpoint. Verify the URL path and the category or table name.

### Conflict

**409** · `type`: `https://docs.trassets.ai/concepts/errors#conflict`

The snapshot changed: the table was re-synced while you paginated. Restart from the first page without `cursor`. See [Pagination](/v1/concepts/pagination).

### Unprocessable Entity

**422** · `type`: `https://docs.trassets.ai/concepts/errors#unprocessable-entity`

A query parameter did not pass validation. Check the `detail` field for the exact parameter and constraint.

### Too Many Requests

**429** · `type`: `https://docs.trassets.ai/concepts/errors#too-many-requests`

You have exceeded the 2,500 requests per hour limit of your API key. Back off and retry after the number of seconds in the `Retry-After` header, see [Rate Limits](/concepts/rate-limits).

Raw table exports have two additional limits with their own `type`: `too_many_parallel_exports` when too many export requests of your account run at the same time, and `export_rate_limited` when an hourly export limit configured for your account or table is used up.

### Internal Server Error

**500** · `type`: `https://docs.trassets.ai/concepts/errors#internal-server-error`

A server-side error occurred. Retry the request after a short delay, and [contact support](#contacting-support) if it persists.

### Service Unavailable

**503** · `type`: `https://docs.trassets.ai/concepts/errors#service-unavailable`

The API is temporarily overloaded or could not validate the request right now. Retry after the number of seconds in the `Retry-After` header.

<Warning>
  A **401** means the `X-API-Key` header is missing or the key has expired. An unknown or disabled key returns **403**, as does a key created for the MCP server or a valid key that lacks the required access tier. Read the `detail` field to tell them apart.
</Warning>

## Contacting support

Every response from the API carries an `X-Request-ID` header with a UUID, error responses included. Responses the load balancer sends on its own carry no ID, such as the redirect from `http://` or a `502` while the API is unreachable. The header is exposed via CORS, so browser clients can read it too. When you contact Trassets support about a request, include its `X-Request-ID`. It identifies exactly that request in our logs, which we keep for 30 days.

```bash
curl -i "https://api.trassets.ai/v1/catalog" \
  -H "X-API-Key: $TRASSETS_API_KEY"
# x-request-id: 0b6c1f3e-5a2d-4c8e-9f71-2d4e6a8b0c13
```

The server always generates the ID. An `X-Request-ID` header sent with the request is ignored.
