<Warning>
  `/v1/` is live but not complete: endpoints are added one table at a time as they pass review. Check the **API Reference** tab (generated from the live `openapi-v1.json`) for what is currently available — do not assume a table listed under the unversioned API is already reachable under `/v1/`.
</Warning>

`/v1/` mirrors the unversioned API's paths under a `/v1/{category}/{api_table}` prefix. A table only appears once it has been reviewed against the [response shape conventions](/v1/response-shape-conventions); until then, keep using the unversioned path for that table.
