<Warning>
  `/v1/` is live but not yet complete: tables are added one at a time. The **API Reference** tab always shows what is available right now — don't assume a table is reachable under `/v1/` just because you've used it before.
</Warning>

`/v1/` serves data under a `/v1/{category}/{api_table}` path prefix, with responses that follow the [response structure](/v1/response-shape-conventions) rules.
