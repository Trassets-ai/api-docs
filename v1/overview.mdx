The Trassets Data API is a read-only REST interface over real-estate data — properties, contracts, accounting, and more — built for software partners and integrators connecting to Trassets-managed portfolios. Every request is authenticated with an `X-API-Key` header; every response is JSON.

This section covers `/v1/`, the API's versioned path family (`/v1/{category}/{api_table}`), with a response shape that's stable per endpoint once published.

## Who this is for

- **Software partners & integrators** building tools on top of Trassets-managed property portfolios.
- **Property managers' own IT teams** connecting internal systems or reporting to live portfolio data.
- **Data & BI teams** feeding data warehouses, dashboards, or analytics pipelines.
