The `/v1/` endpoints are the versioned interface to the same real-estate data. Base URL: `https://api.trassets.ai`. Send your API key in the `X-API-Key` header on every request. All responses are JSON.

Every `/v1/{category}/{api_table}` response is a JSON object with the rows in `data` and the pagination fields next to it. See [Response Structure](/v1/response-shape-conventions) for the object, array, and code/label patterns the rows follow.

## Endpoint types

| Type | Path pattern | Pagination | Use case |
| --- | --- | --- | --- |
| Category endpoints | `/v1/{category}/{api_table}` | Cursor-based (`limit` / `cursor`, `next_cursor` in body) | Business queries, dashboards, incremental fetches |
| Raw endpoints | `/v1/raw/{table_name}` | Cursor-based (`cursor` from `next_cursor` in body) | Bulk sync, full exports, data warehousing |

Raw endpoints are generic per customer (no per-table content review). They use the same response keys as the category endpoints (`total`).

### Pagination

Cursor-only, with the pagination fields in the body: `total` and `next_cursor` (`null` = no further page). There is no `offset`; a request with `offset` returns `400 Bad Request`. Details: [Pagination](/v1/concepts/pagination).

## Error format

Errors follow [RFC 7807](https://datatracker.ietf.org/doc/html/rfc7807) (`application/problem+json`). Every error object contains `type`, `title`, `status`, `detail`, and `instance`. See [Errors](/concepts/errors) for a full list of status codes and retry guidance.

## Versioning

All endpoints live under `/v1/`; unversioned paths return `404`. See [Versioning](/concepts/versioning).

## Catalog and Delta Sync

Two endpoint groups span all categories.

| Group | Endpoint | Purpose |
| --- | --- | --- |
| [Catalog](/v1/api-reference/catalog) | `GET /v1/catalog` | Lists all categories and tables exposed by the API. Use [Data Model Overview](/v1/data-model/overview) for the `/v1/` inventory. |
| [Delta Sync](/v1/api-reference/changes) | `GET /v1/changes` | Reports sync timestamps per table. Requires a `since` parameter (ISO-8601 UTC). |
