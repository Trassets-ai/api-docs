The Data API uses a simple API-key scheme. You pass your key in the `X-API-Key` header on every request. The key determines which customer scope and data tiers you can access.

## Obtaining a key

Trassets sets up the portal access for your organization; there is no public sign-up. With that access, an administrator at your organization logs in at [portal.api.trassets.ai](https://portal.api.trassets.ai) and generates API keys from the dashboard themselves. The plaintext key is displayed exactly once. Copy it immediately and store it in a secure secrets manager. If you lose it, you must revoke the old key and create a new one.

## Passing the key in requests

Include the `X-API-Key` header on every call. Here is a minimal curl example:

```bash
curl "https://api.trassets.ai/property/properties?limit=1" \
  -H "X-API-Key: $TRASSETS_API_KEY"
```

## Key types

Every key has a type, `raw` or `transformed`. The type decides whether the key may read raw source tables. An administrator sets it in the portal; keys created for customers are `transformed`.

| Endpoint | `raw` key | `transformed` key |
| --- | --- | --- |
| Category endpoints (`/{category}/{table}`) | all data | all data, within the key's configured restrictions |
| `GET /raw/{table_name}` | 200 with both personal data grants, otherwise 403 | 403 |
| `GET /raw/tables` | list of tables | empty list |
| `GET /catalog` | all categories and tables | only the categories and tables the key may access |
| `GET /changes` | all changed tables | only changed tables within the key's categories and tables; `?category=X` outside them returns 403 |

A `raw` key cannot carry restrictions. Reading a raw table additionally needs both personal data grants, `personal` and `personal_financial`, because raw tables cannot be split by column; `/raw/tables` lists the tables either way. A `transformed` key gets no raw data and no tables without a category.

If `/raw/tables` is empty although the key is valid, the key is `transformed`. If a raw table returns 403 with `detail` "Raw export requires an API key of type raw with personal data grants. Contact your administrator or Trassets support.", the key is `transformed` or lacks one of the two grants — ask your administrator or Trassets support. A changed key type or grant takes effect within about a minute.

### Property restrictions

A `transformed` key can additionally be limited to a list of property IDs. Category endpoints then return only rows of those properties, and a table that has no `property_id` column (for example `/stakeholder/creditor`) returns 403 for such a key. `/catalog` and `/changes` are not filtered by property; they list tables, not rows. An administrator sets the property list in the portal; a key without a list sees all properties.

## Key storage and security

Trassets never stores your API key in plaintext. Only an HMAC-SHA-256 hash is retained on our servers for verification. This means we cannot recover or display a key after creation.

Treat your key like a password:

- Do not commit it to version control.
- Rotate keys regularly: generate a new key in the portal, switch your integration over, then delete the old one. There is no one-click rotation.
- Scope each key to the minimum access tier your integration needs.

## Authentication errors

If the key is missing, invalid, or does not have the required access tier, the API returns an RFC 7807 problem response.

### 401 Unauthorized

```json
{
  "type": "about:blank",
  "title": "Unauthorized",
  "status": 401,
  "detail": "API key required",
  "instance": "/property/properties"
}
```

This means the request did not include an `X-API-Key` header.

### 403 Forbidden

```json
{
  "type": "about:blank",
  "title": "Forbidden",
  "status": 403,
  "detail": "API key is disabled",
  "instance": "/property/properties"
}
```

A 403 response means the key is not accepted: it is unknown (`Invalid API key`) or disabled (`API key is disabled`), or it is valid but the requested endpoint or data tier is not included in your subscription. Read the `detail` field to tell the cases apart. Contact your account administrator or Trassets support to change your access.
